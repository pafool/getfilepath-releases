# Get File Path

Adds **Get File Path** to the right-click menu in Finder and on the Desktop. Choose it and the file's full path
(like `/Users/you/Desktop/Report.pdf`) is copied, ready to paste.

**Download:** [GetFilePath.dmg](https://github.com/pafool/getfilepath-releases/releases/latest/download/GetFilePath.dmg)

1. Open the downloaded `GetFilePath.dmg`.
2. Drag **GetFilePath** into **Applications**.
3. Open Get File Path from Applications once. It switches itself on and runs quietly in the background from then on.
4. Right-click any file or folder and choose **Get File Path**. Select several files to copy all their paths, one per
   line, or right-click the background of a window or the Desktop and choose **Get Folder Path**.

If the menu item doesn't appear, open Get File Path from Applications again: it shows whether it's switched on and
takes you to the right place in System Settings if it isn't.

Get File Path keeps itself up to date, so you never need to download it again.

_This repository only hosts the app downloads and the update feed (`appcast.xml`)._
